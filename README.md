# Медицинские калькуляторы

Веб-приложение с медицинскими калькуляторами, созданное на Next.js и TypeScript с темным дизайном.

## Функциональность

### 1. Калькулятор коррекции уровня калия
- Расчет дозы аспаркама или калия хлорида 7.5%
- Учет текущего и целевого уровня калия
- Коррекция по весу пациента
- Рекомендации по скорости инфузии и мониторингу

### 2. Калькулятор антибиотикопрофилактики ран
- Подбор антибиотиков согласно современным рекомендациям
- Учет типа раны (чистая, условно-чистая, контаминированная, грязная)
- Коррекция дозы по весу и функции почек
- Учет аллергического анамнеза
- Рекомендации по длительности и частоте введения

### 3. Калькулятор коррекции натрия
- Расчет коррекции гипонатриемии по формуле Адрогуэ-Мадиаса
- Расчет коррекции гипернатриемии по формуле дефицита свободной воды
- Учет пола, возраста и веса пациента для расчета общего объема воды
- Поддержка различных типов инфузионных растворов
- Безопасные протоколы коррекции с рекомендациями по мониторингу

## Технологии

- **Next.js 14** с App Router
- **TypeScript** для типизации
- **Tailwind CSS** для стилизации
- **React** для UI компонентов

## Установка и запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите проект в режиме разработки:
```bash
npm run dev
```

3. Откройте [http://localhost:3000](http://localhost:3000) в браузере

## Особенности дизайна

- Темная тема с белым текстом

- Интуитивная навигация между калькуляторами

## Медицинская информация

⚠️ **Важное предупреждение**: Данные калькуляторы предназначены для информационных целей и помощи медицинским работникам. Все решения о лечении должны приниматься квалифицированным медицинским персоналом с учетом индивидуальных особенностей пациента.
