
# Инструкции по развертыванию

## Локальная разработка

1. **Клонирование репозитория:**
```bash
git clone <repository-url>
cd medical-calculators
```

2. **Установка зависимостей:**
```bash
npm install
```

3. **Запуск в режиме разработки:**
```bash
npm run dev
```

4. **Открытие в браузере:**
Перейдите по адресу [http://localhost:3000](http://localhost:3000)

## Продакшн сборка

1. **Создание продакшн сборки:**
```bash
npm run build
```

2. **Запуск продакшн версии:**
```bash
npm start
```

## Развертывание на Vercel

1. **Подготовка к развертыванию:**
- Убедитесь, что все изменения закоммичены в git
- Проверьте, что проект собирается без ошибок: `npm run build`

2. **Развертывание:**
- Подключите репозиторий к Vercel
- Vercel автоматически определит, что это Next.js проект
- Настройки по умолчанию должны работать корректно

3. **Переменные окружения (если потребуются):**
- В настройках проекта на Vercel добавьте необходимые переменные окружения

## Развертывание на других платформах

### Netlify
1. Подключите репозиторий к Netlify
2. Настройте команду сборки: `npm run build`
3. Настройте папку публикации: `.next`

### Docker
1. Создайте Dockerfile:
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm ci --only=production
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```

2. Соберите и запустите контейнер:
```bash
docker build -t medical-calculators .
docker run -p 3000:3000 medical-calculators
```

## Проверка работоспособности

После развертывания проверьте:

1. **Основная функциональность:**
   - Загрузка главной страницы
   - Переключение между калькуляторами
   - Работа калькулятора коррекции калия
   - Работа калькулятора антибиотикопрофилактики

2. **Адаптивность:**
   - Проверьте на мобильных устройствах
   - Проверьте на планшетах
   - Проверьте на десктопе

3. **Производительность:**
   - Время загрузки страницы
   - Время отклика калькуляторов
   - Оптимизация изображений (если есть)

## Мониторинг

Рекомендуется настроить:

1. **Логирование ошибок:**
   - Sentry или аналогичный сервис
   - Логирование ошибок JavaScript

2. **Аналитика:**
   - Google Analytics
   - Отслеживание использования калькуляторов

3. **Мониторинг производительности:**
   - Vercel Analytics (если используете Vercel)
   - Core Web Vitals

## Обновления

Для обновления приложения:

1. Внесите изменения в код
2. Протестируйте локально: `npm run dev`
3. Создайте продакшн сборку: `npm run build`
4. Закоммитьте изменения
5. Запушьте в репозиторий
6. Платформа автоматически развернет обновления
